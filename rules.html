1. ОБЩИЕ ПОЛОЖЕНИЯ

1.1 Проект GoodBadWorld — это комплекс серверов Minecraft (выживание и другие режимы).

1.2 Правила могут меняться. О значимых изменениях пишем на форуме/Discord проекта.

1.3 Решения главной администрации (tgzaccs, pinio) не обсуждаются. Главная администрация может выдать наказание вне рамок этих правил, если действие вредит проекту.

1.4 Администрация не возвращает ресурсы, потерянные из-за: лагов, киков, багов сервера; действий читеров; действий других игроков.

1.5 Запрещено: продажа, покупка, передача, взлом аккаунтов; продажа/покупка чего-либо за реальные деньги внутри игры (РМТ); распространение личных данных игроков; любой вред проекту.
Наказание: отключение всех аккаунтов без права разбана. Ответственность несёт владелец аккаунта — даже если его взломали или он сам передал аккаунт.

1.6 Правило здравого смысла. Если действие не описано в правилах, но явно портит игру другим — администрация вправе наказать.

2. РЕГИСТРАЦИЯ И АККАУНТ

2.1 Никнейм должен быть адекватным. Запрещены ники:

  • 2.1.1 Похожие на ники администрации (кроме ютуберов проекта)
  • 2.1.2 Сексуального/аморального содержания
  • 2.1.3 Оскорбляющие других игроков
  • 2.1.4 Содержащие названия читов/запрещённого ПО
  • 2.1.5 С нецензурной лексикой
  • 2.1.6 С рекламой других проектов
  • 2.1.7 Связанные со смертью сотрудников проекта

Наказание: блокировка аккаунта. Для сменённых ников — предупреждение, потом блок.

2.2 При покупке платных услуг сохраняй чек. Без чека восстановление невозможно.

2.3 При взломе/утере аккаунта — пиши в техподдержку. Восстановление только при наличии чека и привязки. Безопасность аккаунта — твоя ответственность.

3. ПЛАТНЫЕ УСЛУГИ

3.1 Игра бесплатная. Все покупки — добровольные пожертвования на развитие проекта.

3.2 Возврата средств нет.

3.3 Если оплатил, но услуга не пришла — в техподдержку с чеком.

3.4 Платная группа не даёт права нарушать правила.

7. ПРАВИЛА ПРОВЕРКИ

7.1 Проверка только через Anydesk. Модеры не просят полный доступ — только мышь и клавиатуру.

7.2 Проверка только на ПК. Исключения: Bedrock, PojavLauncher.

7.3 Обязательные программы: SystemInformer, Everything, RecentFilesView, ShellbagAnalyzer, RegScanner, JournalTrace.

7.4 Скачивание только с официальных сайтов/GitHub.

7.5 Mod+ и выше могут проверить FunPay и подобные сайты при подозрении на РМТ.

7.6 Если Anydesk не работает — проверка через Discord.
